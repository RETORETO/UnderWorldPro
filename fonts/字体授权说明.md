# 打包字体授权说明

本目录下的三份字体随游戏一起分发，用于 **Web 导出**时的字体兜底
（见 `Script/Web/WebFontFallback.cs`）。桌面端不加载它们（继续使用系统字体）。

| 文件 | 字体 | 授权 | 来源 |
|---|---|---|---|
| `NotoSansSC-Regular.ttf` | Noto Sans SC 400 | SIL Open Font License 1.1 | https://github.com/google/fonts/tree/main/ofl/notosanssc |
| `NotoEmoji-Regular.ttf` | Noto Emoji 400 | SIL Open Font License 1.1 | https://github.com/google/fonts/tree/main/ofl/notoemoji |
| `DejaVuSans.ttf` | DejaVu Sans 2.37 | Bitstream Vera Fonts License + 公有领域补充 | https://github.com/dejavu-fonts/dejavu-fonts |

## 授权要点

- **SIL OFL 1.1**：允许免费使用、修改、**嵌入并随软件分发**（包括商业软件）；
  要求保留版权声明与授权文本，且不得单独售卖字体本身。
  完整文本见 https://scripts.sil.org/OFL
- **Bitstream Vera / DejaVu**：允许自由使用与再分发，含商业用途；
  要求保留版权声明。DejaVu 在 Vera 基础上追加的字形属公有领域。

三者的授权都允许随游戏分发，无需付费，也不需要把游戏开源。

## 维护提示

`NotoSansSC-Regular.ttf` / `NotoEmoji-Regular.ttf` 由 Google Fonts 的**可变字体**
（`NotoSansSC[wght].ttf` / `NotoEmoji[wght].ttf`）用 fontTools 实例化到 `wght=400`
得到；`DejaVuSans.ttf` 为官方静态字体，未做改动。

若以后 UI 里新增了这三份字体都没收录的字符（罕见汉字的新变体基本不会有，
但新加的 emoji / 特殊符号可能有），Web 端会显示成方框。
排查与补字方法写在 `Web导出环境状态与下一步.md`。
