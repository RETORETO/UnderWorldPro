优先级说明
------------------------------------------------------------
本功能为"纯 UI 展示层"，不读取/修改任何数据或规则（卡牌移动、战斗、调查、出牌、
伤害结算等均不依赖本模块）。可推迟至其他所有系统实现完成后再做，对后续开发无阻塞、
无耦合风险。实现时只改 View（Arena / CardUI 相关），不触碰 Model 与 Controller。


需求与实现规格（已确认）
============================================================

【需求 1】每个非地区实例需挂载两个 Container 节点
  ▲【2026-10-16 已被取代：改为宿主卡角标，见文首状态更新】
- 封印 Container：位于实例 Y 轴偏上。
- 附属 Container：位于实例 Y 轴偏下。
- 两个 Container 的 X 轴位置与实例完全一致（X 对齐实例中心）。
- 渲染层级：两个 Container 整体都在实例之下；其中"附属 Container"的层级高于
  "封印 Container"。
- 实现要点：必须使用【真实 Container 节点】承载，而非"相对宿主卡算固定偏移量"的模拟方式。
  即每个非地区实例 UI 下真实挂两个子 Container，封印/附属卡 AddChild 进对应 Container。

【需求 2】Container 内所有卡纵向均匀排列
  ▲【2026-10-16 已被取代：Container 方案整体废弃，见文首状态更新】
- 每个 Container 内部的卡，按数量纵向等距均匀排列（不是固定累加偏移、也不是重叠挤在一起）。
- 实现要点：改为"按容器内卡数量计算等距步长"的纵向布局，确保多张卡时也不重叠。

【需求 3】封印 Container 内部排序与层级
  ▲【2026-10-16 已被取代：Container 方案整体废弃，见文首状态更新】
- 先加入 Container 的卡：Y 轴偏下，渲染层级更高（压在上面）。
- 后加入 Container 的卡：Y 轴偏上，渲染层级更低。
- 即"新卡往上叠、旧卡在下且压在上面"——与加入顺序相反的方向偏移，ZIndex = 先加入更高。
- 实现要点：ZIndex 公式须为"先加入压后加入"（与现状相反，现状是后加入更高，需修正）。

【需求 4】附属 Container 内部排序与层级
  ▲【2026-10-16 已被取代：Container 方案整体废弃，见文首状态更新】
- 先加入 Container 的卡：Y 轴偏上，渲染层级更高。
- （后加入的卡依次向下、层级更低，对称于封印。）
- ZIndex = 先加入更高（与需求 3 一致，与现状相反，需修正）。
- 实现要点：同需求 3 的层级方向修正。

【需求 5】（空）

【需求 6】实例悬浮按钮 + 展开预览
  ▲【2026-10-16 部分取代：触发形式由"悬浮按钮"改为"角标 hover"；
     但"展开仅 UI 展示、不移动真实卡位置（只读快照/克隆）"约束继续有效。见文首状态更新】
- 每个非地区实例 UI 上添加两个按钮（默认隐藏）：
  * 附属区按钮
  * 封印区按钮
- 显隐规则：仅当鼠标悬浮在该实例上，且对应区域内卡不为空时显示并且可点击。
- 点击行为：
  * 点击附属区按钮 → 展开一个新的 Container，区域内所有附属卡移动到该 Container 内
    横向平铺展示，并支持点击选中卡（仅 UI 展示）。
  * 点击封印区按钮 → 逻辑相同（封印卡）。
- 关键约束：展开预览【仅 UI 展示、逻辑上不移动附属/封印区内卡的真实位置】。
- 实现要点：不能直接把真实 CardUI AddChild 到展开容器（会改变真实父节点，触发布局错乱、
  甚至误触发移动事件）。应采用"只读快照/克隆渲染"方式：读取 CardInstance 数据绘制占位，
  或克隆只读镜像，展开容器关闭后真实卡位置不变。

【需求 7】（空）

横置(IsTapped)占位
------------------------------------------------------------
- 【2026-10-16 措辞更新：Container 纵向排列已取消，但本条**原则**继续有效，已由现有实现承担】
  规则：横置卡在平铺序列中的**占位尺寸一律按竖卡占位列**，否则会重叠（横置仅卡面自身旋转 90°）。
  现由 `CardLayoutHelper.LayoutCardsEvenly` / `LayoutAreaRow` 统一处理（横置视觉宽 = 卡高 140）。
  角标方案下 cat-1「结附/封印于地区」仍走该平铺，本条照旧适用。

性能注意
------------------------------------------------------------
- 每次 OnCardMoved 都会 ArrangeAllCards 全量重排 + 刷新统计。
  ▲【2026-10-16 措辞更新："悬浮按钮显隐 / 展开容器"改为"角标显隐 / hover 浮层"】
    新增角标显隐、展开浮层后，频繁移动时仍须避免每帧重排
    （层叠/平铺均 O(n)，n 通常 < 20，无瓶颈）。
