# 文档索引

> 本目录收纳原根目录的 39 个文档（33 md + 7 txt + Card.xml/验收图）。
> 根目录只保留工程配置、可双击入口脚本，以及 `制作指南/`。
> `制作指南/` **故意不搬**：它是现行制作规范，代码注释（如 `Script/UI/Layers.cs:72`）与大量文档都按 `制作指南/xxx.md` 引用。

## 三条硬规则

1. **本目录不放 `.cs`**。Godot.NET.Sdk 默认 `**/*.cs` glob 不排除自建目录，放进来会被编进 `UWPro.dll`（Web 构建更会因多文件顶级语句直接 CS8805）。
2. **不要把本目录加进 `export_presets.cfg` 的 `include_filter`**，会与 `.gdignore` 冲突。`.gdignore` 只挡编辑器扫描/导入/打包，不影响 `FileAccess.Open("res://文档/…")`（非导出运行时 `res://` 直接映射实体路径）。
3. **以后再移动文档**：改完位置后跑 `python 工具/修正文档链接.py`（先干跑看数字，再加 `--apply`），不要手改相对链接。

## 先看哪几份

- 想跑起来 → `总览/项目现状精简版.md`
- 想知道需求原文 → `总览/核心需求.txt`
- 想做一张卡的效果 → 根目录 `制作指南/`（触发 / 行动 / 持续 / 取单目标 / 附属 / 事务卡 / 原子性 / 双端一致性 / UI 层级）
- 想看当前进度 → `进度与核查/JC卡牌效果进度表.md`（逐效果唯一账本）
- 想知道自检判据 → `进度与核查/JC效果代码核查项.md`

⚠️ **`进度与核查/JC效果代码核查项.md` 的路径被代码读取**：`Script/Tests/JCEffectSelfAuditTests.cs` 里写的是 `ReadProjectText("文档/进度与核查/JC效果代码核查项.md")`。再移动它必须同步改这一行——否则不会编译报错，只会在自检套件里静默记一条「判据文档不可读」违规。
