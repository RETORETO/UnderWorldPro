# 附属卡片制作指南

> 现行有效版（2026-08-11）。旧文档 `文档/归档/旧版制作流程/附属卡片制作流程.md` 保留历史 BUG 记录，本文件为清理后的可执行规范。
> 定位：装备（Equipment）/结附（Attachment）/封印（Seal）卡的制作规范。

> **⚠️ 效果架构说明**：效果代码承载位置为**静态注册类** `Cards/Effects/PlayerCards/XX/卡名_Effects.cs` 的 `Build(PlayerCardData data)` 方法，经 `CardEffectFactory.Register("卡UID", Build)` 登记（详见《触发效果制作指南》§〇）。`.tres` 统一绑定通用 `PlayerCardData`。结附卡的效果（持续/激活/触发）统一写 `data.EffectDataList.Add(...)`。

---

## 一、定位与分类

> 当前代码**仅实现「结附 Attachment」一种附属卡**（`CategoryFlag = CardCategory.Attachment`），代表卡 JC020（结附角色）/ JC012、JC068（结附秘社）/ JC035（结附地区）。装备（Equipment）、封印（Seal）为独立卡型，**尚未实现**（无对应数据结构，本文件不涉及）。

| 类型 | 数据载体 | 结附目标 |
|---|---|---|
| 结附 Attachment | `PlayerCardData` + `CategoryFlag = CardCategory.Attachment` | 角色 / 秘社（`TargetKind.Council`）/ 地区（`TargetKind.Area`） |

- 结附目标由 `data.TargetRules` 声明（`TargetRule.Make(TargetKind.Xxx)`），落在哪个区由结算时 `ResolveEntry` 的 `ResolveKind.Attachment` 分支决定（统一 `ZoneManager.MoveToAttachedZone`，`CurrentZone = AttachedZone`）。

## 二、结附卡制作（现行范式）

### 2.1 结附目标声明（`TargetRules`）

结附目标由 `data.TargetRules` 声明，`TargetRule.Make(TargetKind.Xxx)`，可加敌我/子类别限制：

```csharp
private static void Build(PlayerCardData data)
{
    // 结附于正面角色（Kind=Character 自动排除暗藏者，暗藏者映射为 Covert ≠ Character）
    data.TargetRules = new Godot.Collections.Array<TargetRule>
    {
        TargetRule.Make(TargetKind.Character),
    };

    // 结附于本方秘社（JC012/JC068 范式）
    // data.TargetRules = new Godot.Collections.Array<TargetRule>
    // { TargetRule.Make(TargetKind.Council, TargetRestriction.Friendly) };

    // 结附于地区（JC035 范式）
    // data.TargetRules = new Godot.Collections.Array<TargetRule>
    // { TargetRule.Make(TargetKind.Area) };
}
```

> 结附目标种类：`TargetKind.Character`（角色）/ `TargetKind.Council`（秘社）/ `TargetKind.Area`（地区）。打在哪个目标，结算时 `ResolveEntry` 的 `ResolveKind.Attachment` 分支据此调用 `ZoneManager.MoveToAttachedZone`（`CurrentZone = AttachedZone`）。

### 2.2 效果声明（`EffectDataList`）

结附卡的**持续 / 激活 / 触发效果统一写在 `data.EffectDataList`**（无独立的装备/封印列表字段）：

```csharp
private static void Build(PlayerCardData data)
{
    // 激活效果（附属激活能力，如 JC020 快速行动横置暗藏者）
    data.EffectDataList.Add(new EffectData
    {
        EffectId = "JC020_1_TapCovert",
        Timing = EffectTiming.AttachmentActivated,
        ActivateWindow = "快速",
        ActivateCondition = "横置本角色",
        Target = new TargetSpec { Kind = TargetKind.Covert, NeedsSelection = true, IsLocalZone = true },
        Actions = new Array<EffectAction> { new EffectAction { Verb = ActionVerb.Tap } },
    });

    // 持续效果（如 JC068 全局封锁，用 Scope 声明生效区）
    data.EffectDataList.Add(new EffectData
    {
        EffectId = "JC068_B_BlockDeployCovert",
        Timing = EffectTiming.Continuous,
        Scope = ZoneScope.AttachTarget,   // 附属生效区=仅 AttachedZone
        PrereqSpec = new ContinuousPrereqSpec { Kind = PrereqKind.SelfUntapped },
        StaticEffects = new Array<StaticEffect> { new StaticEffect { Kind = StaticKind.BlockDeployCovert, Param = "" } },
    });
}
```

### 2.3 结附结算流程（现行）

- 打出 → `TurnManager.PlayCard`（`entry.Kind = ResolveKind.Attachment`）→ 结算 `ResolveEntry` 的 `ResolveKind.Attachment` 分支：
  - 结附于角色 → `ZoneManager.MoveToAttachedZone(card, target.ZoneDetailId, ...)`（`ZoneDetailId` = 宿主角色所在地区）。
  - 结附于秘社 → `MoveToAttachedZone(card, 秘社 UID, ...)`。
  - 结附于地区 → `MoveToAttachedZone(card, targetAreaId, ...)`。
- 统一进 `AttachedZone`，`card.IsAttached = true`。
- 静态禁止：`JC001` 的 `CannotBeAttached` 经 `EffectEngine.HasStaticFlag` 拒绝结附。

## 五、制作注意事项

- 结附卡的持续/激活/触发效果统一放 `data.EffectDataList`（无独立装备/封印列表字段）。
- 生效区：结附卡默认 `ZoneScope.AttachTarget`（仅 `AttachedZone` 生效）；显式声明 `Scope` 须与卡实际生效区一致，否则 `IsEffectActiveInZone` 判 false 使效果失效。
- 翻面（`SetCovert`）会注销持续授予（`OnCardStateChanged(CovertChanged)` → `ReevaluateAuras` 自动处理）。
- 夺控换边：目标变己方后若来源的 `TargetRules` 含 `Enemy` 限制，结算复检会判丢失（同取单目标文档 §四）。

## 七、附属激活制作（JC012 帷幕守望徽记范式）

结附秘社的附属卡可带 `Timing = AttachmentActivated` 的激活效果，经通用激活弹窗 `ActivationChoiceWindow` 发动。

### 7.1 两个激活效果的数据范式

- **无目标效果（费用减少类）**：`Target = { NeedsSelection = false }`。动作 verb 用 `费用减少`，`Args` 形如 `["费用减少", "<amt>", "<filter>", "<一次性|整回合>"]`：
  - `amt`：减免点数（如 `1`）。
  - `filter`：玩家级费用修正的匹配过滤串（如 `"帷幕守望"`），空=全匹配。
  - 第四参 `"一次性"`：实现"下一张符合条件的牌 -X"语义（打出/翻面符合条件牌一次后由 `ConsumeCostModification` 消费移除）；省略则整回合全减免。
  - 该动作经 `ApplyCostModification(pid, amt, CurrentTurn, filter, consumeOnce)` 登记玩家级时效费用修正（`pid` 取 `source.ControllerId`），回合结束由 `ExpireTurnEndEffects` 统一出栈还原。

- **取单目标效果（横置/影响角色）**：`Target = { Kind = Character, NeedsSelection = true }`（或 `IncludeCovert=true` 放宽暗藏者）。发动流程见《取单目标效果制作指南》§七。

### 7.2 发动入口（`OpenAttachmentActivateChoice`，`Script/UI/Arena.cs`）

1. `ActivateEligibility.CanActivate(inst, ...)` 判断整卡可发动（受横置/阶段/原子锁限制）。
2. 收集 `inst` 的全部 `ActivationEffects` → 构 `ActivationChoiceItem` 列表。
3. 取目标效果预判断合法目标（`HasLegalTarget`，见《取单目标效果制作指南》§七）：无合法目标则 `item.Disabled = true`，按钮置灰不可点。
4. `ActivationChoiceWindow.Init(items)` 渲染；点击非置灰项：
   - 无目标效果 → `_actionService.ActivateAbility(inst, ab, null)`。
   - 取目标效果 → `BeginAttachmentActivateWithTarget(inst, ab)`：弹窗前再实算合法 UID 集合，只传合法目标给 `RequestActivateTargetSelection`，选完后 `_actionService.ActivateAbility(inst, ab, target)`。

### 7.3 回合生命周期联动

- **回合结束**（`DoPassTurn` → `OnTurnEnded(TurnCount)` → `ExpireTurnEndEffects`）：费用修正等时效项出栈 → `CostModChanged` → `RefreshHandCostReductions`（全体手牌费用标恢复）。
- **回合开始**（`DoPrepare` → `UntapAll`）：遍历含 `AttachedZone` 的所有区，已横置附属随其他卡一起解除横置、费用恢复。

> 制作新附属激活卡时，复用 JC012 的 `ActivationEffects` 声明与发动入口即可；取目标效果合法性只需在数据里写 `Target`，UI 预判断与落点校验由框架统一处理（见《取单目标效果制作指南》§七）。

## 八、附属生效区规则（Z1）与强制触发范式（JC068 阿格斯IV）

### 8.1 附属卡生效区规则（方案C：声明式生效区，默认仅 AttachedZone）

**默认规则**：附属卡只有在**附属区（AttachedZone）**时才生效——其**触发 / 持续 / 激活**效果默认均不生效（AreaZone/资产/手牌/墓地的附属不生效）。角色卡默认仅 `AreaZone` 生效。

**统一判定**（方案C，三处共用 `EffectEngine.IsEffectActiveInZone(e, card)`）：
| 效果 | 落点 | 判定 |
|---|---|---|
| 持续/静止 | `EffectEngine.RegisterPersistent`（Static + Continuous 分支） | `IsEffectActiveInZone(e, card)` |
| 触发 | `TriggerRegistry` 内层 foreach | `IsEffectActiveInZone(e, card)` |
| 激活 | `ActivateEligibility.CanActivate` 内层 foreach | `IsEffectActiveInZone(e, card)` |

**生效区声明**：
- 附属卡未声明 `Scope`（`Specified`）→ 默认 `AttachTarget` = 仅 `AttachedZone`（严格版，Z1/Z4）。
- 附属卡显式声明 `Scope` → 按声明（如未来"部分附属可作为角色卡在 AreaZone 生效"可声明 `AreaZone`；"墓地生效"可声明 `Graveyard`）。
- **⚠️ 声明必须与卡实际生效区一致**，否则效果失效。

> **结附路径规范（Z4）**：后续所有结附路径统一进 `AttachedZone`。`ResolveEntry` 行990「打牌结附到角色走 `MoveCardToArea`（AreaZone）」是早期无规范遗留，暂无在用卡，暂不调整，后续统一修正；并核查结附秘社/地区路径是否符合。

### 8.2 JC068 阿格斯IV 范式（结附秘社附属：强制触发 + 全局封锁）

**卡文**（两效果 + 结附目标）：
- 结附于本方秘社：`TargetRules = { TargetRule.Make(TargetKind.Council, Friendly) }`。
- 效果A（强制触发）：准备步骤，支付 1（横置1张资产区牌），否则横置阿格斯IV。
- 效果B（持续）：只要阿格斯IV未横置，对手就不能进行秘密派遣行动。

**效果A（准备维护 `PrepareUpkeep` + 强制选择窗）**：
```csharp
data.EffectDataList.Add(new EffectData
{
    EffectId = "JC068_A_Upkeep",
    Timing = EffectTiming.OnTurnStarted,
    Forced = true,                                  // 强制触发：不能放弃
    Scope = ZoneScope.AttachTarget,
    Actions = new Array<EffectAction> { new EffectAction { Verb = ActionVerb.PrepareUpkeep, Args = new Array<string>{ "1" } } },
});
```
- `PrepareUpkeep`：经注入 `EffectEngine.PromptPayOrTap` 弹"支付N/横置来源"二选一窗，选支付 `SpendMana(N)`、选横置 `SetTapped(true)`。
- **强制选择窗**：`ActivationChoiceWindow.ForceChoice = true`（不显示取消按钮 + 点窗外不关闭），玩家必须二选一才能继续（`PrepareUpkeep` 分支由 Arena 自动设 `ForceChoice`）。

**效果B（全局封锁 `BlockDeployCovert` + 自身未横置前提）**：
```csharp
data.EffectDataList.Add(new EffectData
{
    EffectId = "JC068_B_BlockDeployCovert",
    Timing = EffectTiming.Continuous,
    Scope = ZoneScope.AttachTarget,
    PrereqSpec = new ContinuousPrereqSpec { Kind = PrereqKind.SelfUntapped },   // 自身未横置前提
    StaticEffects = new Array<StaticEffect> { new StaticEffect { Kind = StaticKind.BlockDeployCovert, Param = "" } },
});
```
- `PrereqKind.SelfUntapped`：新增前提类型（来源卡自身未横置），`EvaluatePrereq` 分支 `return !card.IsTapped`。
- `StaticKind.BlockDeployCovert`：新增全局封锁静止效果，作用于"控制者的对手"，`EffectEngine` 登记封锁表，`TurnManager.DeployCovert` 实时拦截。
- 横置/重置即时开关依赖 `SetTapped` 统一事件链（见《持续效果制作指南》§2.7）。

### 8.3 制作清单（强制触发 + 全局封锁附属）
- [ ] 结附目标 `TargetRules`（秘社/地区/角色）。
- [ ] 强制触发：`Forced=true` + `PrepareUpkeep` 动词 + `ForceChoice` 强制选择窗。
- [ ] 全局封锁：`StaticKind.BlockDeployCovert` + `PrereqKind.SelfUntapped` 前提。
- [ ] 确认该附属在 `AttachedZone`（生效区）注册持续效果。
