# 持续效果制作指南

> 现行有效版（2026-08-11）。旧文档 `持续效果制作流程.md` 保留历史缺口/BUG 记录，本文件为清理后的可执行规范。
> 定位：持续（B组）效果的**制作规范**。通用默认需正面朝上（公开）才生效（见 §〇-1）。

---

## 〇-1、通用红线：效果默认正面朝上才生效

- 持续/光环/触发/行动效果未显式声明时，仅当源卡与目标卡均 `!IsCovert` 才生效。
- 翻面（`SetCovert`）经总线 `OnCardStateChanged(CovertChanged)` → `ReevaluateAuras` 自动注销/恢复，无需手动画线。

---

## 一、持续效果定位

| 维度 | 持续效果（B组） |
|---|---|
| 时机 | `EffectTiming.Continuous` / `Static` |
| 入堆叠 | ❌ 不入堆叠 |
| 失效 | 离场/封印/区域变更/前提不满足时注销 |

## 二、✅ 已规范制作范式

> **承载位置（2026-08-14 架构迁移后）**：以下各效果代码均写在**静态注册类** `Cards/Effects/PlayerCards/XX/卡名_Effects.cs` 的 `Build(PlayerCardData data)` 方法里，并通过 `CardEffectFactory.Register("卡UID", Build)` 登记（系列 `XXEffects.RegisterAll()` 聚合，顶层 `AllEffects.RegisterAll()` 由 `GameInitializer` 开局前调用）。**原来的 `EffectDataList.Add(...)` 一律改为 `data.EffectDataList.Add(...)`**（效果由 `CardManager.CreateCardInstance` 内 `CardEffectFactory.EnsureEffects(data)` 按 `data.UID` 填充）。`.tres` 统一绑定通用 `PlayerCardData`，不再每卡一个类。详见《触发效果制作指南》§〇。

### 2.1 数据结构（持续专用字段）
```csharp
public EffectTiming Timing = EffectTiming.Continuous;
public ZoneScope Scope = ZoneScope.HandZone;          // Static 按 AreaZone 生效；Continuous 暂不按 Scope 联动
public Array<EffectGrant> ContinuousGrants;           // { Kind="Keyword"|"Icon"|"Attribute"|"MagicDomain", Value, Amount }
public ContinuousPrereqSpec PrereqSpec;               // 结构化前提（优先于文本）
```

### 2.2 自身关键字授予（JC014「公开」）
```csharp
var e = KeywordEffects.Public();   // Static? 否，Continuous + 授予 Keyword="公开"
e.EffectId = "JC014_1_Public";
data.EffectDataList.Add(e);
```
链路：`RegisterPersistent` → `Grant` → `HasPublicKeyword`。

### 2.3 静止/禁止（JC001「不能被装备结附」）
```csharp
var e = KeywordEffects.CannotBeAttached();   // Static + AreaZone + StaticEffects=[CannotBeAttached]
e.EffectId = "JC001_1_NoAttach";
data.EffectDataList.Add(e);
```
链路：`RegisterPersistent` → `AddStaticFlag` → 消费点 `EffectEngine.HasStaticFlag` 拒绝结附。

### 2.4 条件持续属性（JC001「心心→白眼」）
```csharp
data.EffectDataList.Add(new EffectData
{
    EffectId = "JC001_B_WhiteEye",
    Timing = EffectTiming.Continuous,
    Scope = ZoneScope.AreaZone,
    PrereqSpec = new ContinuousPrereqSpec
    {
        Kind = PrereqKind.DomainLoyalty, Domain = MagicDomain.Mind, Amount = 2, Zone = CardZone.AssetZone
    },
    ContinuousGrants = new Array<EffectGrant> { new EffectGrant { Kind="Attribute", Value="先手调查", Amount=1 } }
});
```
前提开关靠 `EffectEngine.ReevaluatePrereqs(playerId)`：建立资产显式调一次；所有 move 经 `ZoneManager.FireMoved`→`OnPostMove` 自动触发。

### 2.5 影响他者光环（JC060「神秘学顾问」）
```csharp
var aura = new EffectData
{
    EffectId = "JC060_Aura",
    Timing = EffectTiming.Continuous,
    Scope = ZoneScope.AreaZone,
    IsAura = true,
    AuraFilterExcludeDomain = MagicDomain.Mind,
    ContinuousGrants = new Array<EffectGrant>
    {
        new EffectGrant { Kind="Icon", Value="心", Amount=1 },
        new EffectGrant { Kind="Attribute", Value="战斗", Amount=1 },
        new EffectGrant { Kind="MagicDomain", Value="Mind", Amount=1 },
    }
};
data.EffectDataList.Add(aura);
```
引擎：`RegisterPersistent`→`ApplyAura`（对自身授予后遍历同控制者争夺区、排除 `AuraFilterExcludeDomain` 的他者 `Grant`）；`ReevaluateAuras(playerId)` 差量重算（进场/离场/夺控自动刷新）；`UnregisterPersistent` 精确撤销。UI 经 `OnVisualDirty`→`Arena.SyncDerivedUI` 收口。

### 2.6 线性计量条件持续（JC018「每 1 点心灵忠诚 → +1 黑刀」）
与 §2.4 同 `PrereqSpec`，多开 `ScaleByLoyalty=true`；授予量 `= Amount × N`（`N=GetDomainLoyalty[Domain]`），`ReevaluatePrereqs` 增量重算避免叠加。

### 2.7 全局封锁静止效果（JC068「阿格斯IV：未横置时对手不能秘密派遣」）

**前提类型扩展**：`PrereqKind.SelfUntapped`（来源卡自身未横置）。`EvaluatePrereq` 分支 `return !card.IsTapped`。这是继 `DomainLoyalty` 之后的第二种前提类型，也是首个"来源自身状态"前提。

**效果载体**：`StaticKind.BlockDeployCovert`（全局封锁）。与 §2.3 `CannotBeAttached`（作用于自身）不同，`BlockDeployCovert` **作用于他者玩家**，由 `EffectEngine` 登记"控制者的对手"到全局封锁表，`TurnManager.DeployCovert` 实时查询拦截。

```csharp
var block = new EffectData
{
    EffectId = "JC068_B_BlockDeployCovert",
    Timing = EffectTiming.Continuous,
    Scope = ZoneScope.AreaZone,
    ContinuousPrereq = "阿格斯IV未横置",
    PrereqSpec = new ContinuousPrereqSpec { Kind = PrereqKind.SelfUntapped },
    StaticEffects = new Array<StaticEffect>
    {
        new StaticEffect { Kind = StaticKind.BlockDeployCovert, Param = "" }
    },
};
data.EffectDataList.Add(block);
```

链路：`RegisterPersistent`（前提满足时登记封锁对手派遣）→ `ReevaluatePrereqs`（横置/竖置即时开关）→ `UnregisterPersistent`（离场解除）→ 消费点 `TurnManager.DeployCovert` 2.3 步 / `CanPlayerDeployCovert`。

**横置即时开关（关键）**：效果前提依赖 `IsTapped`，横置/重置变化必须走 `CardInstance.SetTapped(bool)`（发 `TappedChanged`）→ `Arena` 状态总线 → `ReevaluatePrereqs` 即时重判。所有横置/重置路径（回合重置 `UntapAll`/`UntapAssets`、PM `tap`/`untap`、效果动词 `ActionVerb.Tap`/`Untap`、激活横置本角色、准备维护横置）**统一走 `SetTapped`**，杜绝直接赋值 `IsTapped` 绕过事件链导致封锁不同步。

**全局封锁查询**：`EffectEngine.IsDeployCovertBlocked(playerId)` 返回该玩家是否被任一未横置阿格斯封锁。扩展其他"全局封锁"类效果（如封锁行动/调查）可仿照新增 `StaticKind` + 封锁表。

### 2.8 附属卡生效区规则（Z1：仅 AttachedZone）

**规则（2026-08-16 确认）**：附属卡只有在**附属区（AttachedZone）**时才生效——其触发/持续/激活效果均不生效（AreaZone/资产/手牌/墓地的附属不生效）。角色卡仍仅 `AreaZone` 生效。

**落点**（三处统一，`CardCategory.Attachment` 判定）：
- **持续**：`EffectEngine.RegisterPersistent` 入口——附属卡且 `CurrentZone != AttachedZone` 则跳过注册。
- **触发**：`TriggerRegistry` 触发源判定——附属卡仅 `AttachedZone` 可触发。
- **激活**：`ActivateEligibility.CanActivate`——附属卡仅 `AttachedZone` 可激活。

> 后续规范（Z4）：所有结附路径统一进 `AttachedZone`（含 `ResolveEntry` 行990 打牌结附角色遗留的 AreaZone 路径），并核查结附秘社/地区路径。

### 2.9 声明式生效区（方案C，统一判定）

**核心**：把"卡效果在哪个区生效"从"按卡类型硬编码"改为"每个 `EffectData` 声明自己的 `Scope`"（MTG 静态能力"默认+覆盖"模型）。

**统一判定入口**（`EffectEngine`，三处共用，勿在调用处重复写区判断）：
- `GetDefaultScope(card)`：卡类型默认区——附属→`AttachTarget`（严格=仅 AttachedZone），角色→`AreaZone`（仅 AreaZone）。
- `IsEffectActiveInZone(e, card)`：`e.Scope != Specified` 用声明，`Specified` 回退默认区。

**三处收敛**：
| 效果 | 落点 | 判定 |
|---|---|---|
| 持续/静止 | `RegisterPersistent`（Static + Continuous 分支） | `IsEffectActiveInZone(e, card)` |
| 触发 | `TriggerRegistry` 内层 foreach | `IsEffectActiveInZone(e, card)` |
| 激活 | `ActivateEligibility.CanActivate` 内层 foreach | `IsEffectActiveInZone(e, card)` |

**`ZoneScope` 枚举**（声明值）：`AreaZone`/`HandZone`/`AttachTarget`/`AssetZone`/`Graveyard`(未来)/`DeckZone`(未来)/`Specified`。

**声明规则**：
- 未声明（`Specified`）→ 走卡类型默认，行为与 Z1 严格规则一致（旧卡自动兼容，低回归）。
- 显式声明 → 按声明生效区（同卡不同效果可不同区，如"手牌时+X""墓地时可发动"）。

**⚠️ 注意**：显式声明 `Scope` 必须与卡的实际生效区一致，否则 `IsEffectActiveInZone` 会判 false 使效果失效。

## 三、制作清单（通用）

- [ ] `Timing=Continuous`/`Static`，`Scope` 填预期区域。
- [ ] 带前提必须用 `PrereqSpec`（勿依赖旧文本 `ContinuousPrereq` 判定）。
- [ ] `ContinuousGrants` 填 `Kind/Value/Amount`。
- [ ] 通用词条经 `KeywordEffects.Xxx()` 封装；补 `EffectId`（卡号_序号_关键词）。
- [ ] `data.EffectDataList.Add(...)`（写在静态注册类 `Build` 方法里，见 §二 顶部说明）。
- [ ] 光环设 `IsAura=true` + `AuraFilterExcludeDomain`。
